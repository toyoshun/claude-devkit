# 新しいプロジェクトの最初のメッセージ

新しいプロジェクトの最初のスレッドに、そのまま貼る。Claude がリポジトリと環境を affi-lab と同じ形に整える。

```
このプロジェクトを claude-devkit（https://github.com/toyoshun/claude-devkit）の形で立ち上げてください。README の「新しいプロジェクトの始め方」に従い、次を済ませて、終わったら結果を短く報告してください。
1. ~/.claude/skills/devkit が入っているか確かめる。なければ claude-devkit の install.sh を実行し、環境のセットアップスクリプトを templates/cloud-setup.sh と同じにする提案を出す。
2. リポジトリに CLAUDE.md がなければ作る。中身はこのリポジトリの目的、確認コマンド（lint・型・テスト）、止めて聞くこと、守ること。既にあれば足りないものだけ足す。
3. このリポジトリだけの振り分けがあれば .claude/pstack-route.md に、編集直後に回したい検査があれば .claude/devkit.json に書く。なければ作らない。
4. CI がなければ、確認コマンドを回す最小のワークフローを足す。
5. 変更は PR にして、CI が緑になったらマージしてよい。
6. このプロジェクトで決まったこと（目的、使うサービス、オーナーの方針）をプロジェクトの記憶に残す。
```
