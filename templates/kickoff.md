# 新しいプロジェクトの最初のメッセージ

新しいプロジェクトの最初のスレッドに、そのまま貼る。Claude がリポジトリと環境を affi-lab と同じ形に整える。

```
このプロジェクトを claude-devkit（https://github.com/toyoshun/claude-devkit）の形で立ち上げてください。README の「新しいプロジェクトの始め方」に従い、次を済ませて、終わったら結果を短く報告してください。
1. ~/.claude/skills/devkit が入っているか確かめる。なければ claude-devkit の install.sh を実行し、環境のセットアップスクリプトを templates/cloud-setup.sh と同じにする提案を出す。環境のネットワークが制限ありなら、制限なしにするようオーナーに伝える（作ったばかりの環境は制限ありで始まり、外部のAPIが使えないため）。
2. リポジトリが空（コミットなし）なら、main に空の初回コミットを1つ push してから作業ブランチを切る。PR の土台がないため。
3. リポジトリに CLAUDE.md がなければ作る。中身はこのリポジトリの目的、確認コマンド（lint・型・テスト）、止めて聞くこと、守ること。既にあれば足りないものだけ足す。
4. このリポジトリだけの振り分けがあれば .claude/pstack-route.md に、編集直後に回したい検査があれば .claude/devkit.json に書く。なければ作らない。
5. CI がなければ、確認コマンドを回す最小のワークフローを足す。
6. 変更は PR にして、CI が緑になったらマージしてよい。
7. claude-devkit をこのプロジェクトのリポジトリに加える。汎用のスキルやルールを作ったときに、そこへ PR を出せるようにするため。
8. このプロジェクトで決まったこと（目的、使うサービス、オーナーの方針）をプロジェクトの記憶に残す。
```
